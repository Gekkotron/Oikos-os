## Seams for the UI plan
- `state_changed` WS events now mean a real change (value, attributes or availability); equal-value reports are not broadcast. `last_update` means last report.
- An `asLight` switch has `kind: light`, `capabilities.brightness: false` and a `state.value` of type `on_off`, not `light`.
- `AreaView.entity_count` counts every entity; `primary_count` is what the cards show.
- `part_of` children (e.g. a cover's `moving` sensor) carry state the parent card may want.
- `Unassigned` is an area id; `Snapshot.areas` order is the chip order.
- Sensor values `unknown`/`unavailable` arrive as `Text`; render them as a dash.
