# Flow List Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the web Flows page usable at 50+ flows: search, status and trigger filters, sort, list grouped by room (default) / ungrouped list / cards, and a hand-set room per flow (editor, list menu, MCP).

**Architecture:** `oikos_core::flow::Flow` gains `area: Option<String>`. The hub validates it on write (with a stale-id exemption), exposes `POST /api/v1/flows/{id}/area`, fills invalid-flow stubs with `name`/`area` from the raw JSON, and MCP surfaces the field. The web gets a pure `flow_list` module (classification, filtering, grouping, sorting, prefs), tested natively, and a rebuilt `screens/flows/` UI on top of it.

**Tech Stack:** Rust; axum + rmcp hub (`oikos-os`); Leptos 0.8 CSR (`oikos-web`); serde.

**Spec:** `docs/superpowers/specs/2026-10-22-flow-list-design.md` (read it with this plan).

## Global Constraints

- A flow's `area` is an **area id** (`AreaView.id` / `Area.id`), serialized as `"area"`, omitted when `None`.
- `UNASSIGNED_AREA` (`"Unassigned"`) is never a valid flow area; flows without a room are "No room".
- A stale `area` (room deleted) must never block a save: the hub accepts an `area` equal to the one already stored for that flow id.
- Loading retained flows stays lenient: an unknown `area` never makes a flow invalid.
- Web helpers in `crates/oikos-web/src/flow_list.rs` are pure (no leptos, no `web_sys`) so `cargo test -p oikos-web` runs them natively, like `flows.rs`.
- `localStorage` key `oikos.flowList`; every access fallible and silent (pattern in `theme.rs`). Search text is never stored.
- Commits as Gekkotron: `git -c user.name=Gekkotron -c user.email=60887050+Gekkotron@users.noreply.github.com commit …`, message ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Before each commit: `cargo fmt --all` and `cargo clippy --workspace --all-targets -- -D warnings` clean.

## Review Focus

1. **A room deleted after flows were assigned to it** — the flows show under "No room", the editor still saves, `set_flow_enabled` still works. Pinned by Task 2 `stale_area_is_kept_on_resave` and Task 4 `rows_treat_unknown_area_as_no_room`.
2. **A broken (invalid) flow inside a folded room** — the section header shows ⚠. Pinned by Task 4 `section_flags_attention`.
3. **MCP caller passes a room *name* instead of an id** ("Living room") — resolved to the id like overrides do. Pinned by Task 2 `area_name_resolves_to_id`.
4. **Search with accents/case** ("salon" vs "Salon", "entrée" vs "entree") — matches. Pinned by Task 4 `search_folds_case_and_accents`.
5. **Corrupt or old `oikos.flowList` value in storage** — page falls back to defaults, no panic. Pinned by Task 4 `prefs_decode_garbage_is_default`.

  ```rust
  pub const NO_ROOM_KEY: &str = "__no_room__";
  pub enum TriggerKind { State, Schedule, Sun, Signal, Manual }
  pub enum StatusFilter { #[default] All, On, Off, Attention }
  pub enum Sort { #[default] Name, LastRun }
  pub enum Grouping { #[default] Room, None }
  pub enum ViewMode { #[default] List, Cards }
  pub struct ListRow { pub view: FlowView, pub trigger_text: String,
                       pub kinds: BTreeSet<TriggerKind>,  // empty for an invalid flow
                       pub room: Option<String>,          // a known area id, else None
                       pub room_name: Option<String>, pub attention: bool }
  pub struct Filters { pub query: String, pub status: StatusFilter, pub triggers: BTreeSet<TriggerKind> }
  pub struct StatusCounts { pub all: usize, pub on: usize, pub off: usize, pub attention: usize }
  pub struct Section { pub key: String, pub title: String, pub rows: Vec<ListRow>, pub attention: bool }
  #[derive(Default, Serialize, Deserialize)] #[serde(default)]
  pub struct FlowListPrefs { pub view: ViewMode, pub grouping: Grouping, pub sort: Sort,
                             pub status: StatusFilter, pub triggers: BTreeSet<TriggerKind>,
                             pub folded: BTreeSet<String> }

  pub fn needs_attention(view: &FlowView) -> bool;
  pub fn trigger_kinds(view: &FlowView) -> BTreeSet<TriggerKind>;
  pub fn rows(flows: &[FlowView], areas: &[AreaView], entities: &BTreeMap<String, EntityView>) -> Vec<ListRow>;
  pub fn filter(rows: &[ListRow], f: &Filters) -> Vec<ListRow>;
  pub fn status_counts(rows: &[ListRow], query: &str, triggers: &BTreeSet<TriggerKind>) -> StatusCounts;
  pub fn sort_rows(rows: &mut [ListRow], sort: Sort);
  pub fn sections(rows: Vec<ListRow>, areas: &[AreaView]) -> Vec<Section>;
  pub fn decode_prefs(raw: &str) -> FlowListPrefs;   // garbage → default
  pub fn encode_prefs(p: &FlowListPrefs) -> String;
  ```
- Rules (from the spec): *attention* = invalid, or the first run in `runs` (newest first) whose status is `Done` or `Failed` is `Failed`. *Kinds*: one per trigger node type; a valid flow with none is `{Manual}`; an invalid flow is `{}`. *Filter*: query (folded case+accents) is a substring of the folded name, description, `trigger_text` or `room_name`; status `On` = enabled && !invalid, `Off` = !enabled; trigger set empty = all, else `kinds ∩ set ≠ ∅`. *Counts* apply query + trigger set, ignore status. *Sort* `Name` = folded name; `LastRun` = newest `runs[0].started_at` first, never-run last, ties by name. *Sections* follow `areas` order (the hub's order), skipping `UNASSIGNED_AREA` and rooms with no rows, then `NO_ROOM_KEY` titled "No room" last; row order inside a section is preserved; `attention` = any row's `attention`.
