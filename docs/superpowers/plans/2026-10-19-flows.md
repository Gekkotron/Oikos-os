# Flows (n8n-style automations) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Node-graph automations ("flows") stored as retained JSON on the broker, run by the hub, written through MCP and REST, and shown in the web UI as a read-only n8n-style canvas with the last run lit.

**Architecture:** `oikos-core::flow` holds the pure model (nodes, edges, lenient decode, strict validation, duration and scalar comparison, graph helpers shared with the web). `oikos-api` adds the wire views, two WebSocket events and `Snapshot.flows`. In `oikos-os`, a `FlowStore` behind the hub keeps definitions and in-memory runs; an `Engine` task subscribes to hub events, starts one tokio task per run (abortable), and reports steps back through the hub, which broadcasts them. The web gets a Flows list, a canvas screen (HTML node cards over an inline SVG of Bézier wires) and live run updates.

**Tech Stack:** Rust 2024, tokio, axum 0.8, rmcp 3.5, schemars 1, serde, Leptos 0.8 CSR with Trunk, hand-written CSS, wasm-bindgen-test.

**Spec:** `docs/superpowers/specs/2026-10-19-flows-design.md`

## Global Constraints

- Topics: flows live on `<automation_prefix>/<flow_id>`, default `[topics] automation_prefix = "oikos/automation"`; an empty retained payload deletes a flow.
- `[automation] runs_kept = 20` runs per flow, in memory only.
- Flow id `[a-z0-9_-]{1,64}`; node id `[a-z0-9_-]{1,32}`; `mode` is `single` (default) or `restart`; `enabled` defaults to `true`.
- Node types: exactly `trigger.state`, `if`, `delay`, `command`. `if` ops: `eq ne gt lt gte lte`. Durations: integers with `s`, `m`, `h` units, concatenated (`"1h30m"`), non-zero.
- Unknown top-level keys and unknown `params` keys round-trip verbatim (`#[serde(flatten)] extra`).
- Ingest validates structure only; entity and command checks run on `set_flow` and `PUT`; a missing entity at run time fails that step.
- The engine fires a trigger only on a known-to-known scalar change, never on an availability-only change, and clears its known map when the broker link leaves `Online`.
- A failing node ends the run `failed`; a node with several incoming edges runs once per arrival.
- List-carrying `WsEvent` variants are struct variants (`FlowsChanged { flows }`, `FlowRunChanged { flow_id, run }`).
- Every web URL that interpolates a flow or run id goes through `crate::api::encode_id`.
- `oikos-core` and `oikos-api` stay wasm-clean; gates: `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt --all --check`, `cargo check -p oikos-core --target wasm32-unknown-unknown`, same for `oikos-api` and `oikos-web`.
- Commits: `git -c user.name=Gekkotron -c user.email=60887050+Gekkotron@users.noreply.github.com commit …`, message ending with the session's `Co-Authored-By` and `Claude-Session` lines.

## Review Focus

- A retained payload whose `id` field differs from the topic's last segment: the flow must be `invalid` with reason `id mismatch`, never silently renamed (test in Task 4).
- A hub restart: retained flows then retained states replay, and no run may start (test in Task 6, `boot_replay_starts_nothing`).
- Deleting or disabling a flow during its `delay`: the run ends `cancelled` and the `turn_off` command is never published (tests in Task 6).
- An `if` with `gt` against a bool scalar: the node fails, the run ends `failed`, nothing panics (test in Task 6).
- A `trigger.state` with `to: "true"` (a string) on an on/off entity never fires, since `eq` is typed (test in Task 6).

- Behaviour:
  - Loop on `select!` over `hub.subscribe()` events, `requests`, and the completion of run tasks (keep a `JoinSet<(String /*flow_id*/, String /*run_id*/, RunStatus)>`; on completion call `hub.end_run` unless the run was cancelled by the engine, which already ended it).
  - `StateChanged { id, state }`: `next = Scalar::of_state(&state.value)`; `prev = known.get(id)`; if the entity is watched: when `prev` is `None` (never seen) → store, no fire; when `prev == Some(Some(p))` and `next == Some(n)` and `p != n` → for each flow, for each `trigger.state` node on `id` whose `to`/`from` (via `Scalar::from_json`, `eq` semantics) match → `fire(flow, node, TriggerInfo { entity, value: n.to_json(), previous: p.to_json() })`; always store `next`.
  - `ConnectionChanged(status)` with `status != Online`, and `RecvError::Lagged`: `known.clear()`.
  - `Reload`: `flows = hub.flow_definitions()` filtered on `enabled`; seed `known` for every newly watched entity from `hub.entity_scalar` (as `Some(scalar)`, so a flow written while the entity already has a value fires on its next change); for each `active` whose flow is now absent, disabled or `!=` the stored one → abort the task, `hub.end_run(.., Cancelled)`.
  - `Run { flow_id, run_id }`: spawn `execute` from the flow's first trigger node with `trigger: None`.
  - `fire`: if `active` has the flow: `Single` → `hub.add_skipped_run(flow_id, node.id, Some(trigger))`; `Restart` → abort, `end_run(Cancelled)`, then begin. Then `hub.begin_run(flow_id, Some(trigger))` and spawn `execute(hub, flow, run_id, start_node, trigger)`.
  - `execute`: depth-first with an explicit stack of node ids, starting at the trigger node. Per node: `trigger.state` → step `Ok`, detail `"{entity} = {value}"` (or `"manual"`); `if` → entity = `params.entity` or the trigger's, missing in a manual run → `Failed` "no triggering entity"; scalar from `hub.entity_scalar`; `compare` → port `"true"`/`"false"` as detail, `Err` → `Failed` with the error text; `delay` → `tokio::time::sleep(parse_duration(..))` then `Ok` with detail `"waited {for}"`; `command` → `hub.send_command(entity, cmd).await`: `Ok(accepted: true)` → `Ok` detail `"accepted"`, `Ok(accepted: false, reason)` → `Failed` with reason, `Err(e)` → `Failed` with `e.to_string()`. Each step goes through `hub.record_step` before the successors are pushed (in reverse so edge order is preserved). A `Failed` step returns `RunStatus::Failed`; reaching the end returns `Done`.
